# 实用提词器网页版

纯静态网页，无框架、无后端依赖。文稿、舞台设置和阅读位置保存在当前浏览器的 `localStorage` 中。支持当前行聚焦、中央参考线、段落跳转、提纲、镜像、全屏、键盘快捷键、移动手势、TXT 导入导出和离线缓存。

## 安装到 iPad（离线使用）

1. 先把 `web` 文件夹部署到支持 HTTPS 的静态网站。
2. 在 iPad 上使用 Safari 打开网址，并保持联网等待页面完全打开。
3. 点击 Safari 的分享按钮，选择“添加到主屏幕”，再点击“添加”。
4. 从 iPad 主屏幕打开“提词器”一次。之后断网也能打开、编辑文稿和提词。

注意：文稿保存在当前 iPad 的本地存储中。删除主屏幕应用、清除 Safari 网站数据或更换域名可能导致本地文稿丢失，重要文稿请定期使用“导出 TXT”备份。

## 本地运行

不要直接双击 HTML，建议在 `web` 目录启动静态服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 部署

将 `web` 文件夹内的全部文件上传至任意静态网站托管服务。部署后必须使用 HTTPS，浏览器本地数据按域名分别保存。
